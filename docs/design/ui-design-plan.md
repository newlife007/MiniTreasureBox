# MiniTreasureBox UI 设计方案

## 1. 设计目标

MiniTreasureBox 是一款本地优先的桌面工具箱，包含 AI 工具、实用工具、本地文件搜索和轻量小游戏。界面设计应让用户在几秒内完成三件事：

1. 找到目标工具。
2. 看懂工具用途和数据处理方式。
3. 完成处理并复制、保存或导出结果。

产品不采用聊天式 AI、复杂控制面板或在线办公软件的视觉语言。整体方向是一个安静、可靠、打开即用的桌面工具工作台。

核心关键词：

- 轻盈
- 温暖
- 清晰
- 本地优先
- 可靠
- 有一点探索感

设计示意图见 [ui-home-mockup.svg](ui-home-mockup.svg)。

## 2. 设计原则

### 2.1 单任务优先

用户通常带着一个明确任务进入应用，例如识别图片、格式化 JSON、转换时间戳或搜索本地文件。页面应优先展示搜索、分类和最近使用，不引入复杂的工作流编排。

### 2.2 本地状态清晰可见

应用中的工具默认在本机运行。界面应在导航区、工具卡片和工具详情页明确显示“本地运行”或“需要网络连接”状态。

用户应能理解：

- 图片、文字和文件不会自动上传。
- 收藏、最近使用和窗口状态保存在本机。
- OCR 和图像处理正在本机执行。

### 2.3 自动处理必须有人工兜底

OCR 和试卷复原等工具需要展示处理状态、失败原因、取消入口和重试入口。试卷复原还必须保留原图、Mask、复原结果、撤销、重做和导出前检查。

### 2.4 保留可预测的返回路径

`Esc` 返回、`Ctrl/Cmd + K` 搜索、收藏、最近使用和分类导航是核心桌面交互。视觉重构不能改变这些行为，也不能清空用户的搜索条件和分类上下文。

### 2.5 与现有 Qt Widgets 架构一致

第一阶段继续使用 Qt 6 Widgets。设计通过现有的页面、布局、工具卡片、调色板和动态样式实现，不额外引入 QML 技术栈，也不让首页直接依赖某个具体工具实现。

## 3. 视觉风格

### 3.1 整体风格

- 大面积浅灰背景。
- 白色浮层和工具卡片。
- 深蓝黑色主文字。
- 靛青色作为主强调色。
- 青绿色表示本地、安全和完成状态。
- 琥珀色表示处理中或需要注意。
- 红色只用于错误和危险操作。
- 图标使用统一的线性图形，不使用 Emoji 作为主要图标。
- 不使用高饱和霓虹色、大面积粒子效果或自动轮播。

建议宽度约 216–230 像素，分为三组：

```text
工作台
  首页
  AI 工具
  实用工具

    编码转换
    时间工具
    文本工具

  收藏

```

选中项使用浅色主色背景、主色文字和左侧 3 像素强调条。导航文本、`UserRole`、对象名和动态分类逻辑必须保留。

导航底部固定展示：

```text
● 全部在本机运行
  不会自动上传你的内容
```

### 4.2 首页欢迎区

首页顶部使用：

```text
今天想完成什么？
本地工具、AI 处理和小游戏，都在这里。
```

搜索框高度建议为 52–58 像素，圆角 14–15 像素。搜索模式选择器位于搜索框左侧，搜索框右侧显示 `Ctrl K` 或 `Cmd K` 提示。

## 5. 首页内容

### 5.1 常用工具

根据收藏和最近使用动态生成，建议展示 3–5 个工具。没有使用记录时，可以展示 OCR、JSON 格式化和文本统计等默认推荐。

工具卡片显示：

- 图标
- 工具名称
- 一句话描述
- 分类
- 本地运行状态
- 收藏状态
- 打开入口

### 5.2 AI 工作台

AI 工具使用较大的双列卡片展示：

- 图片 OCR
- 试卷复原

AI 卡片可以分别使用浅紫色和浅薄荷色背景，但颜色必须保持低饱和度，并保证文字对比度。

### 5.3 实用工具分类

首页不要一次展示所有实用工具。推荐展示分类入口：

- 开发工具
- 编码转换
- 时间工具
- 文本工具

分类入口显示分类名称、工具数量和一句描述。具体数量必须从注册表动态计算，不能硬编码到 UI。

### 5.4 小游戏

小游戏卡片和游戏工作台使用轻量主题色区分，但避免幼稚化：

- 猜数字：琥珀色
- 2048：橙色
- 贪吃蛇：绿色
- 俄罗斯方块：蓝色
- 五子棋：红棕色

游戏详情页统一使用“状态卡 + 当前指标 + 最佳指标 + 游戏舞台 + 操作说明 + 控制栏”的结构。画布提供键盘焦点环和暂停、胜利、失败、平局遮罩；状态遮罩使用 160ms 的淡入反馈，不阻塞游戏输入。猜数字展示动态有效范围和最近猜测，2048 使用离散数字块色阶，贪吃蛇区分蛇头和身体，俄罗斯方块显示七种方块色、幽灵落点和下一个方块，五子棋显示木色棋盘、星位、最后一步与获胜连线。浅色和深色主题均从应用调色板派生背景与文字颜色。

玩法配置位于游戏工作台顶部，切换后开始新一局。猜数字提供经典与限次挑战以及三档范围；2048 提供经典与 80 步挑战、每局一次撤销、移动计数和连续合并奖励；贪吃蛇提供经典、穿墙和固定障碍模式，并随等级加速、周期性生成奖励食物；俄罗斯方块提供三档初始速度、等级加速、方块暂存、三个后续方块预览和连续消行奖励；五子棋提供本地双人、简单 AI、普通 AI、先后手选择和悔棋。本地统计按游戏和模式分别记录游玩、完成、最佳成绩与最长连胜，保留既有最高分、胜局和音效设置。

游戏页面循环播放低音量的 CC0 曲目“8-Bit Space Adventure Theme — looped section”，来源和文件哈希记录在 `resources/audio/README.md`。背景音乐使用单例播放器，进入游戏页时播放，离开游戏页、关闭开关或应用进入后台时停止或暂停，避免多个页面重叠播放。原先的系统报警音已移除。

## 6. 工具卡片

### 6.1 结构

```text
┌──────────────────────────┐
│  [图标]                  ☆ │
│                          │
│  JSON 格式化与校验        │
│  美化、压缩并检查 JSON    │
│                          │
│  开发工具   ● 本地运行    │
└──────────────────────────┘
```

建议：

- 最小高度约 176–184 像素。
- 圆角 14 像素。
- 内边距 16–18 像素。
- 图标区域约 40–48 像素，使用浅色圆角背景。
- 标题字号约 16 像素。
- 收藏按钮使用星形图标。
- 主要打开按钮使用主色背景。

### 6.2 交互状态

默认状态使用细边框和轻微阴影。悬停或聚焦时，卡片边框变为主色，并轻微提升背景对比度。卡片必须继续支持：

- 鼠标双击打开
- `Enter` 打开
- `Return` 打开
- `Space` 打开
- 收藏按钮键盘操作

### 6.3 可访问性

必须保留现有对象名和辅助功能信息：

- `toolName`
- `toolDescription`
- `toolCategory`
- `toolNetworkState`
- `favoriteButton`
- `openButton`

## 7. 工具详情页

工具详情页统一使用：

```text
← 返回首页     分类 / 工具名称                 ☆ 收藏
工具描述
● 完全在本机运行，不会上传内容

┌──────────────────────────────────────────────┐
│                  工具实际工作区              │
└──────────────────────────────────────────────┘

[返回上一页]
```

顶部必须显示工具名称、描述、分类、本地状态和收藏入口。底部保留“返回上一页”按钮和 `Esc` 返回行为。

工具工作区内部继续由具体工具实现负责，主窗口不应把工具逻辑硬编码到首页。

## 8. OCR 页面

OCR 页面采用左右双栏：

```text
┌──────────────────┐  ┌────────────────────────────┐
│  拖入图片         │  │ 识别结果                   │
│                  │  │                            │
│  选择文件         │  │ 识别后的文字显示在这里     │
│  从剪贴板粘贴     │  │                            │
└──────────────────┘  └────────────────────────────┘

语言：[简体中文 + 英文]                    [开始识别]
```

必须覆盖四种状态：

- 等待输入
- 正在识别
- 识别完成
- 识别失败

失败状态应告诉用户原因和恢复方式，例如修复安装、重新安装或重试。

## 9. 试卷复原页面

试卷复原页面应突出可检查性：

- 原图
- Mask
- 复原结果
- 画笔
- 橡皮擦
- 矩形工具
- 撤销和重做
- 按住查看原图
- 导出前风险提示

导出前提示用户确认结果，因为复杂纹理和被覆盖内容无法保证无损恢复。

## 10. 本地文件搜索

本地文件搜索是首页的第二种工作模式。应用启动后在后台自动建立本机固定磁盘的文件名和路径索引，用户无需先选择目录。

推荐结构：

```text
[本地文件]  搜索本机全部固定磁盘中的文件名或目录路径

正在扫描 / 搜索结果 / 文件结果列表
```

结果行应显示：

- 文件或目录图标
- 路径
- 匹配原因
- 打开文件
- 打开所在目录

索引建立、取消、更新、过期结果丢弃和文件 watcher 生命周期必须继续由 `LocalFileSearchWidget` 管理。

设置页建议分组：

  主题
  紧凑模式

  清理最近使用

  聚焦搜索

主题选择可以使用三个预览卡片：跟随系统、浅色、深色。主题切换必须即时生效，并通过现有 `Settings` 持久化。

## 12. 字体、间距和动效

### 字体

优先使用当前平台系统字体，避免跨平台缺字或渲染差异。

### 字号

| 内容 | 建议字号 |
| --- | ---: |
| 页面主标题 | 26–28 px |
| 区块标题 | 18 px |
| 工具名称 | 16 px |
| 正文 | 14 px |
| 辅助文字 | 12–13 px |
| 按钮 | 14 px |

### 间距

统一使用 4 的倍数：

- 页面边距：28–32 px
- 区块间距：24–28 px
- 卡片间距：14–16 px
- 控件间距：8–12 px

### 动效

- 卡片悬停：160 ms
- 页面切换：180–220 ms
- 状态提示：淡入淡出
- 处理中：轻量进度动画

避免自动轮播、粒子效果和影响键盘使用的动画。

## 15. 验收标准

### 视觉

- 浅色主题符合颜色 Token 和圆角卡片规范。
- 深色主题保持文字和背景足够对比度。
- 侧栏、首页搜索、工具卡片、本地状态卡具有统一视觉语言。
- 普通窗口尺寸下工具宫格不出现水平滚动条。

### 功能

- 首页搜索仍能筛选当前视图。
- 分类、收藏、最近使用仍能正确过滤工具。
- 工具打开、收藏、返回和快捷键行为不变。
- 本地文件搜索仍能建立索引、搜索、更新和打开结果。
- OCR、试卷复原和小游戏页面可正常打开。

### 测试

- Python OCR 打包脚本回归测试通过。
- Windows 原生完整构建通过。
- macOS Intel 原生完整构建通过。
- macOS Apple Silicon 原生完整构建通过。
- 14 个 CTest 全部通过。
- 应用启动、OCR smoke、安装包启动和卸载测试通过。
