# Dataset manifests

Only de-identified IDs and rights metadata belong in Git. Images, labels, source evidence, and personal data stay in approved private storage. Each template group is assigned wholly to train, validation, or test. A withdrawn, expired, unlicensed, or hash-mismatched item must be removed from all processing immediately.

`manifest.example.json` may be created locally from generated fixtures, but real manifests and split outputs are ignored because even de-identified operational lists can reveal dataset composition.
